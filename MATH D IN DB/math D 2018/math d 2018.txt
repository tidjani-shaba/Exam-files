Voici la résolution complète et détaillée de l'épreuve de Mathématiques du Baccalauréat Série D (Session 2018, OBC Cameroun).Exercice 1 (/4 points)Question 1)Instruction(s) :On considère $a$ et $b$ deux réels, avec $a$ non nul.Question :Démontrer que les fonctions de la forme $x \mapsto C e^{ax} - \frac{b}{a}$, où $C$ est un réel, sont des solutions de l'équation différentielle : $y' = ay + b \quad (E)$ (on admettra par la suite que ce sont les seules).Section 1 : Solution(s)Soit $f$ la fonction définie sur $\mathbb{R}$ par $f(x) = C e^{ax} - \frac{b}{a}$, où $C \in \mathbb{R}$.Méthode 1 : Par vérification directe (Substitution dans l'équation)Calculons la dérivée $f'(x)$ :$$f'(x) = \frac{d}{dx}\left(C e^{ax} - \frac{b}{a}\right) = C \cdot (a e^{ax}) - 0 = a C e^{ax}$$Exprimons le membre de droite $a f(x) + b$ :$$a f(x) + b = a \left(C e^{ax} - \frac{b}{a}\right) + b = a C e^{ax} - b + b = a C e^{ax}$$On constate que pour tout $x \in \mathbb{R}$, $f'(x) = a f(x) + b$.Donc, toute fonction de la forme $x \mapsto C e^{ax} - \frac{b}{a}$ est solution de l'équation différentielle $(E)$.Méthode 2 : Par résolution directe de l'équation différentielleL'équation $(E)$ s'écrit $y' - ay = b$.Résolution de l'équation homogène $y' - ay = 0$ :Les solutions sont $y_h(x) = C e^{ax}$, avec $C \in \mathbb{R}$.Recherche d'une solution particulière constante $y_p(x) = k$ :$y_p'(x) = 0 \implies 0 = a k + b \implies k = -\frac{b}{a}$.La solution générale est la somme $y(x) = y_h(x) + y_p(x) = C e^{ax} - \frac{b}{a}$.Réponse explicite :Toutes les fonctions $x \mapsto C e^{ax} - \frac{b}{a}$ ($C \in \mathbb{R}$) vérifient $y' = ay + b$.Section 2 : Explication détailléeExplication pas à pas :Pour montrer qu'une fonction donnée est solution d'une équation différentielle, il suffit d'injecter la fonction et sa dérivée dans l'équation et de vérifier que l'égalité est respectée pour tout $x$.La dérivée de $e^{u(x)}$ est $u'(x) e^{u(x)}$. Ainsi, la dérivée de $e^{ax}$ est $a e^{ax}$.La constante $-\frac{b}{a}$ a pour dérivée $0$.En remplaçant $y$ par $C e^{ax} - \frac{b}{a}$ dans $a y + b$, le terme $-b$ simplifié par $+b$ redonne exactement $a C e^{ax}$, qui est égal à $y'$.Piège ou difficulté :Le piège classique est d'oublier de dériver correctement l'exposant $ax$ (oublier de multiplier par le coefficient $a$). Un autre piège est de penser qu'il faut démontrer l'unicité alors que l'énoncé demande seulement de démontrer que ces fonctions sont des solutions (la réciproque étant admise d'après le texte).Ce que l'examinateur attend :L'examinateur veut voir le calcul explicite de la dérivée $y'$, l'expression claire de $ay + b$, et la conclusion affirmant l'égalité $y' = ay + b$.Barème OBC (1 point) :Calcul correct de la dérivée $f'(x) = a C e^{ax}$ : 0,5 ptSubstitution dans l'équation et conclusion : 0,5 ptQuestion 2)Instruction(s) :Pour chacune des trois affirmations suivantes, indiquer si elle est vraie ou fausse.Question 2) a)Question :Affirmation 1: si une fonction $f$ définie sur l'ensemble des nombres réels $\mathbb{R}$ est solution de l'équation différentielle $y' + 3y = 6$ alors la courbe représentant $f$ admet une asymptote horizontale en $+\infty$.Section 1 : Solution(s)L'équation s'écrit $y' = -3y + 6$. Ici $a = -3$ et $b = 6$.D'après la question 1), les solutions sont de la forme :$$f(x) = C e^{-3x} - \frac{6}{-3} = C e^{-3x} + 2 \quad (C \in \mathbb{R})$$Calculons la limite en $+\infty$ :$$\lim_{x \to +\infty} f(x) = \lim_{x \to +\infty} (C e^{-3x} + 2)$$Puisque $\lim_{x \to +\infty} e^{-3x} = 0$, on a $\lim_{x \to +\infty} f(x) = 2$.Comme la limite en $+\infty$ est une constante finie ($2$), la droite d'équation $y = 2$ est une asymptote horizontale à la courbe représentant $f$ en $+\infty$.Réponse explicite :Affirmation 1 : VRAIE.Section 2 : Explication détailléeExplication pas à pas :On résout $y' + 3y = 6 \iff y' = -3y + 6$.On applique la formule générale trouvée à la question 1 avec $a = -3$ et $b = 6$. La solution est $f(x) = C e^{-3x} + 2$.Lorsque $x$ tend vers $+\infty$, $-3x$ tend vers $-\infty$, donc $e^{-3x}$ tend vers $0$.$f(x)$ s'approche donc de la valeur constante $2$. Par définition, la droite $y = 2$ est une asymptote horizontale.Piège ou difficulté :Attention au signe dans l'exposant ! L'équation est $y' + 3y = 6$, donc $y' = -3y + 6$, le coefficient $a$ vaut $-3$ (négatif). Si on avait commis l'erreur de prendre $a = 3$, la limite aurait été infinie.Ce que l'examinateur attend :La justification n'est pas obligatoirement exigée pour une question "Vrai/Faux", mais l'écriture de l'expression de $f(x)$ et la limite en $+\infty$ garantissent le point.Barème OBC (1 point) :Réponse "VRAIE" avec justification/forme correcte de la solution : 1 ptQuestion 2) b)Question :Affirmation 2: si une fonction $f$ définie sur l'ensemble des nombres réels $\mathbb{R}$ est solution de l'équation $y' = y$ alors pour tous réels $\alpha$ et $\beta$, $f(\alpha+\beta) = f(\alpha) \times f(\beta)$.Section 1 : Solution(s)Méthode 1 : Analyse algébriqueL'équation $y' = y$ a pour solutions $f(x) = C e^x$ avec $C \in \mathbb{R}$.Calculons $f(\alpha + \beta)$ et $f(\alpha) \times f(\beta)$ :$f(\alpha + \beta) = C e^{\alpha + \beta} = C e^\alpha e^\beta$$f(\alpha) \times f(\beta) = (C e^\alpha) \times (C e^\beta) = C^2 e^{\alpha + \beta}$Pour que $f(\alpha + \beta) = f(\alpha) \times f(\beta)$ soit vraie pour tous $\alpha, \beta \in \mathbb{R}$, il faut que $C = C^2$, soit $C = 0$ ou $C = 1$.Si $C = 2$ (par exemple $f(x) = 2e^x$, qui est bien solution de $y' = y$), on a :$f(0+0) = f(0) = 2$, mais $f(0) \times f(0) = 2 \times 2 = 4 \neq 2$.L'affirmation n'est donc pas vraie pour toute solution $f$.Réponse explicite :Affirmation 2 : FAUSSE.Section 2 : Explication détailléeExplication pas à pas :Une affirmation universelle du type "si $f$ est solution, alors..." signifie que la propriété doit être vraie pour toutes les fonctions solutions.Les solutions de $y'=y$ sont $f(x) = C e^x$.La propriété fonctionnelle $f(\alpha+\beta) = f(\alpha)f(\beta)$ caractérise la fonction exponentielle exacte ($C=1$) ou la fonction nulle ($C=0$).Dès que la constante $C \neq 0$ et $C \neq 1$, cette relation est fausse. Un contre-exemple suffit à prouver qu'une affirmation est fausse : pour $f(x) = 2e^x$, $f(0) = 2$, mais $f(0)\times f(0) = 4 \neq f(0)$.Piège ou difficulté :Confondre la propriété de la fonction exponentielle classique $e^{a+b} = e^a e^b$ avec la fonction générale $C e^x$. Donc :$$\mathcal{A} = \left[ \frac{3}{2} \left(-\frac{1}{2} e^{-2x}\right) \right]_0^{\ln(3)} = \left[ -\frac{3}{4} e^{-2x} \right]_0^{\ln(3)}$$$$\mathcal{A} = -\frac{3}{4} e^{-2\ln(3)} - \left(-\frac{3}{4} e^{0}\right)$$Rappel : $e^{-2\ln(3)} = e^{\ln(3^{-2})} = 3^{-2} = \frac{1}{9}$.$$\mathcal{A} = -\frac{3}{4} \times \frac{1}{9} + \frac{3}{4} = -\frac{1}{12} + \frac{9}{12} = \frac{8}{12} = \frac{2}{3}$$Réponse explicite :Affirmation 3 : VRAIE.Section 2 : Explication détailléeExplication pas à pas :Trouver la fonction : $y' = -2y \implies f(x) = C e^{-2x}$.
