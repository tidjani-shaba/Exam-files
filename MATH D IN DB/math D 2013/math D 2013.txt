(0,5 pt)Section 1 : Solution(s)Méthode 1 (Calcul du discriminant $\Delta$) :Calculons le discriminant :$$\Delta = (-4)^2 - 4(1)(8) = 16 - 32 = -16 = (4i)^2$$$\Delta < 0$, donc l'équation admet deux racines complexes conjuguées :$$z_1 = \frac{-(-4) - 4i}{2(1)} = \frac{4 - 4i}{2} = 2 - 2i$$$$z_2 = \frac{-(-4) + 4i}{2(1)} = \frac{4 + 4i}{2} = 2 + 2i$$Méthode 2 (Forme canonique) :$$z^2 - 4z + 8 = 0 \iff (z - 2)^2 - 4 + 8 = 0 \iff (z - 2)^2 + 4 = 0$$$$(z - 2)^2 = -4 \iff (z - 2)^2 = (2i)^2 \iff z - 2 = 2i \quad \text{ou} \quad z - 2 = -2i$$$$z_1 = 2 + 2i, \quad z_2 = 2 - 2i$$Réponse finale : $S = \{2 - 2i\,;\, 2 + 2i\}$Section 2 : Explication détailléeExplication pas à pas :Pour résoudre une équation du second degré $az^2 + bz + c = 0$ à coefficients réels dans l'ensemble des nombres complexes $\mathbb{C}$, on utilise la même méthode que dans $\mathbb{R}$.
